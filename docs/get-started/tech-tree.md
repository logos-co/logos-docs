# Procedure tech tree

#### See which procedures build on which, and find a path through the docs from where you are now.

Each box is a procedure. An arrow leads from a prerequisite to every procedure that lists it under **Prerequisites**, which are also the pages in its **Next steps** section. Columns count the longest chain of prerequisites before a procedure, so the first column holds the procedures you can start with.

## Diagram

Hover over a procedure, or tap it on a touch screen, to highlight what it needs and what it leads to. Click it, or tap it again, to open it.
